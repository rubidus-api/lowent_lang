# `lowdiff` — 두 폴더를 **내용으로** 비교한다

```sh
lowdiff before/ after/
```

작업 폴더와 백업(또는 배포) 폴더가 정말 같은지 묻는 일은 흔하다. 그 답을 **크기와
수정시각**으로 때우면 **조용히 틀린다** — 길이가 같고 내용만 다른 경우가 실제로 있다.
이 도구는 바이트를 본다.

## 무엇을 말하나

한 줄이 하나의 발견이고, 순서는 **결정적**이다(디렉터리마다 이름 오름차순, 하위 디렉터리는
그 뒤). 종료 코드로도 답한다: 같으면 0, 다르면 1.

바깥 오라클은 `diff -rq` 다 — 같은 나무에 대해 같은 발견을 말해야 한다.

자세한 것은 [`doc/manual.md`](doc/manual.md).
