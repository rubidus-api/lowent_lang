# 2. 문법의 기본 — 토큰·상수·주석

[← 목차](README.md) · [← 1. 빌드와 실행](01-build-and-run.md)

## 주석

두 가지가 있다:

```lowent
rem 여기부터 줄 끝까지가 줄 주석이다.

note END
  여러 줄에 걸치는 블록 주석. 여는 낱말과 같은 종결자(여기선 END)로 닫는다.
END
```

`rem` 은 줄 주석, `note <종결자> … <종결자>` 는 블록 주석이다(종결자는 아무 낱말이나 된다).
(임의의 바이트·여러 줄 **데이터**가 필요하면 `text` 히어독을 쓰는데, 그건 주석이 아니라
값이다.)

## 모듈과 종결자

모든 파일은 모듈 선언으로 연다:

```lowent
module demo .
```

Lowent 는 특수문자를 최대한 아낀다. 문장·절의 끝은 **홀로 선 마침표 `.`** 로 맺고, 블록은
**`do … end`** 로 감싼다. 구조체·열거형·op 도 `end` 로 닫는다. 괄호 `( )` 는 수식의 묶음에만
쓴다.

## 상수(리터럴)

- **정수**: 십진 `42`, 16진 `0xFF`, 2진 `0b1010`. 자릿수 사이에 `_` 를 구분자로 넣을 수
  있다(`1_000_000`).
- **부동소수**: `3.14`, 지수 `6e-3`, 16진 부동 `0x1.8p3` 도 된다.
- **문자열**: `"…"`. **이스케이프 집합이 닫혀 있다** — 아래 **열넷**뿐이고, 그 밖의
  이스케이프는 `E-STR-ESCAPE` 로 거절된다. (여러 줄은 `text` 히어독의 원본 본문을 쓴다.)

  | 적는 것 | 뜻 | | 적는 것 | 뜻 |
  |---|---|---|---|---|
  | `\\` | 역슬래시 | | `\v` | 세로 탭 |
  | `\"` | 큰따옴표 | | `\0` | 영 바이트 |
  | `\'` | 작은따옴표 | | `\xNN` | 십육진 **두 자리** |
  | `\a` | 경보 | | `\uXXXX` | 코드포인트, **네 자리** |
  | `\b` | 한 칸 뒤로 | | `\UXXXXXXXX` | 코드포인트, **여덟 자리** |
  | `\f` | 쪽 넘김 | | | |
  | `\n` | 줄 바꿈 | | | |
  | `\r` | 줄 처음으로 | | | |
  | `\t` | 가로 탭 | | | |

  - `\uXXXX`·`\UXXXXXXXX` 는 **코드포인트를 적고**, 그것이 몇 조각으로 실릴지는 **접두사가**
    정한다: `"\U0001F600"` 은 바이트 **4**, `u"…"` 은 UTF-16 **2**(서러게이트 쌍),
    `U"…"` 은 코드포인트 **1** 이다. 서러게이트 자리(D800~DFFF)와 10FFFF 초과는 거절된다.
  - **팔진 이스케이프는 없다.** 이 언어에는 팔진 표기가 아예 없다(`0755` 는 755다) —
    리터럴에만 되살리면 그 자리가 언어의 유일한 예외가 되기 때문이다.
  - **접두사는 둘**이다: `u`(UTF-16 코드 유닛) · `U`(코드포인트). 없으면 바이트다.
    `u8"…"` 은 **없다** — 접두사 없는 것과 완전히 같아서 동의어를 두지 않았다.
  - `\xNN` 은 **임의의 한 바이트**(`\x00`–`\xff`, 대소문자 무관). 자릿수는 **정확히 둘**이라
    `"\x41e"` 는 `A` 다음에 `e` 두 바이트다 — 한 자리(`"\x7"`)나 16진이 아닌 자리는 거절된다.
    C·C++ 의 `\x` 는 16진수를 끝없이 먹어서 리터럴 옆에 글자 하나가 붙으면 값이 조용히
    달라진다. Rust·Zig 는 그것을 길이 고정으로 닫았고(가변인 것은 중괄호를 쓰는 `\u{…}` 뿐),
    여기도 같은 규율이다. 문자열이 `slice u8` 이라 Rust 의 `str` 과 달리 0x7F 제한도 없다.
- **불리언**: `true` / `false`. 부재값: `none`.

```lowent
fn lits output u64 . do
  let hex u64 be 0xFF .        rem 255
  let bin u64 be 0b1010 .      rem 10
  return add hex bin .         rem 265
end
```

## 스칼라 타입

`bool`, 부호 없는 `u8 u16 u32 u64`, 부호 있는 `i8 i16 i32 i64`, 포인터폭 `usize isize`, 부동
`f32 f64`. 이 위에 `slice`, `option`, `result`, `vec`, `mask`, `ref`/`mut_ref`, `cap` 같은
낱말이 타입을 수식한다.

> `u128`/`i128` 은 아직 없다(post-v1). 폭 집합은 `{u8..u64, i8..i64, usize, isize}` + `f32/f64`.

## 낱말(키워드)

핵심 키워드는 **43개**로 닫혀 있다 — 목록에 없는 낱말은 키워드가 되지 않는다.
대략의 갈래:

- 선언: `module use type newtype struct enum trait contract actor state`
- op: `fn proc export unsafe extern`
- 지역·흐름: `let var set return if else for while guard match case try break continue expr`
- 값: `make true false none be`
- 동시성·기타: `spawn send drop test expect satisfies do end`

☞ **낱말이 아닌데 낱말처럼 보이는 것 둘**: `neg`(단항 부호 반전)은 **내장 op** 이고
  ([3장](03-ops.md)), `range`(범위 타입)는 **타입 생성자**다([8장](08-types.md)).
  키워드 43 개에 안 들어가지만 도구는 둘 다 안다.

옛 낱말 일부(`calcop procop local as in to loop give …`)는 **삭제**되어 `E-VOCAB-REMOVED` 로 거절된다 — 사라진
것을 조용히 받아주지 않는다.
