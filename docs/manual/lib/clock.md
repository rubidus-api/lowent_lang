# clock — 시각과 마감

소스: `lib/clock.low` · 모듈명 `clock` (RFC-0090 N1)

## 처음 쓰는 사람에게

**무엇을 하는 모듈인가.** *"지금 몇 시인가"* 와 *"얼마나 지났나"* 와 *"언제까지인가"* 를 답한다.

**시계를 읽는 것은 `io` 가 아니다** (2026-09-06 소유자 결정). 정본 §7.1 이 `io` 를
*"바깥과 자료를 주고받는다(파일·연결·표준 입출력)"* 라 적는데, 시각을 읽는 것은 자료를
주고받지 않는다. 그래서 시계 잎은 **효과를 적지 않고**(`effects none`), 결정성을 깨는 일이라는
사실은 **권한**(`cap clock`)이 나른다. 예외는 하나 — `sleep_ms` 는 `wait` 이다
(*"기다린다. 다른 누구의 도움 없이도 언젠가 깨어난다"* — 정본의 그 원자가 정확히 이것이다).
☞ 효과를 크게 적으면 부르는 쪽이 **없는 비용**을 떠안는다: 순수한 op 이 시계를 못 쓰게 된다.

**왜 `cap clock` 인가.** 시계는 **결정성을 깬다** — 같은 입력에 다른 답이다. 이 언어의 권한
여덟은 *"세상에 닿는가"* 로만 갈리지 않고, **결정성을 깨는가**로도 갈린다. 그래서 시계를 쓰는
op 은 시그니처에 그 사실을 달고 다닌다(`cap random` 이 같은 이유로 갈린 짝이다).

**최소 예제 — 마감을 두고 일한다.**

```lowent
use clock .

proc work input k cap clock . output u64 . effects none . do
  let due u64 be clock.deadline_in k 50 .          rem 지금부터 50 ms
  var n u64 be 0 .
  while clock.past k due . do ... end             rem 지났으면 그만
  return n .
end
```

## 두 축 — 단조 시각과 벽시계

| | 단조(monotonic) | 벽시계(local) |
|---|---|---|
| op | `now_ns`·`now_ms`·`since_ns`·`since_ms`·`sleep_ms`·`deadline_in`·`past`·`left_ms` | `local_packed` + `year_of`·`month_of`·`day_of`·`hour_of`·`minute_of`·`second_of` |
| 무엇을 약속하나 | **뒤로 가지 않는다** — 그래서 *지속*을 재는 데 쓴다 | 사람이 읽는 날짜/시각 |
| 무엇을 약속 **안** 하나 | 절대 시각(기준점은 뜻이 없다) | **단조성** — 시간대·서머타임·보정으로 **뒤로 갈 수 있다** |

★ **지속을 잴 때 벽시계를 쓰지 마라.** 이 표가 있는 이유가 그것이다: 두 시계는 이름만
비슷하고 약속이 다르다.

★★ `local_packed` 는 여섯 값을 **한 u64 에 담아** 준다(연·월·일·시·분·초). 푸는 짝(`year_of` …)은
**순수**하다 — 권한 없이 쓸 수 있고, 그래서 시각을 **받아서** 다루는 코드는 시계를 안 받아도 된다.

## 오라클 — 무엇을 주장할 수 있나

이 모듈에 대해 골든이 주장하는 것은 **단조성과 순서**뿐이다. 절대 시각은 **대볼 것이 없어서**
주장하지 않는다(무엇이 옳은지 아무도 모른다). 없는 구별을 시험으로 지어내지 않는다.

## 표면

| op | 모양 | 비고 |
|---|---|---|
| `now_ns` · `now_ms` | `(cap clock) → u64` | 단조 |
| `since_ns` · `since_ms` | `(cap clock, start u64) → u64` | 지난 만큼 |
| `sleep_ms` | `(cap clock, ms u64) → u64` | 실제로 잔 시간 |
| `deadline_in` | `(cap clock, ms u64) → u64` | 마감 시점 |
| `past` · `left_ms` | `(cap clock, deadline u64) → bool` / `u64` | 마감 판정·남은 시간 |
| `local_packed` | `(cap clock) → u64` | 벽시계 여섯 값을 담은 한 값 |
| `year_of` … `second_of` | `(p u64) → u64` | **순수** — 푸는 짝 |

## 안 지은 것 (정직히)

시간대 · 달력 산술(윤년·월말) · 형식화 · 타이머/알람 · 단조 시계의 기준점.
