# math — 부동소수 수학

소스: `lib/math.low` · 모듈명 `math` (RFC-0090 N2)

## 처음 쓰는 사람에게

**무엇을 하는 모듈인가.** `sqrt`·`sin`·`exp` 같은 빌트인 위에, 자주 쓰는 것들을 얹는다 —
비교(`close`), 상수(`pi`·`e`), 각도 변환, 빗변, 밑이 있는 로그, 선형 보간.

**권한이 없다**(순수 계산). 다만 libm 에 붙으므로 **호스트 전용**이다 — freestanding 프로파일에는
부동소수 자체가 없을 수 있다(`cortex_m` 은 `no_float`).

> ## ⚠ **`==` 로 비교하지 마라 — `close` 를 써라**
>
> ```lowent
> guard math.close (math.hyp 3.0 4.0) 5.0 0.000001 . else return 1 .
> ```
>
> 부동소수는 *"같다"* 가 잘 정의되지 않는다. 그래서 이 모듈은 **`close(a, b, tol)`** 을 주고,
> 라이브러리 자신의 시험도 그것으로 판정한다.

## 오라클이 **비트가 아닌** 이유 (이 모듈에서 가장 중요한 문단)

`libm` 은 **구현마다 마지막 자리가 다를 수 있다**. 정확한 비트를 주장하면 다른 기계·다른 libc
에서 **거짓 실패**가 난다 — 도구가 멀쩡한데 시험이 우는 것이다.

⇒ 이 모듈의 오라클은 **알려진 답**(예: `sin(0) = 0`)과 **항등식**(예: `sin²+cos² = 1`,
`exp(log x) = x`)이고, 판정은 `close` 로 한다. **`tol` 을 쓰는 사람이 적게** 만든 것도 같은
이유다: 얼마나 가까우면 같다고 볼지는 **부르는 쪽의 문제**이지 라이브러리가 정할 것이 아니다.

## 표면

| op | 하는 일 |
|---|---|
| `close` | `|a-b| ≤ tol` — **이 모듈의 비교 방식** |
| `pi` · `e` | 상수 |
| `deg_to_rad` · `rad_to_deg` | 각도 변환 |
| `hyp` | `sqrt(x² + y²)` |
| `log_base` | 밑이 있는 로그(`log x / log b`) |
| `lerp` | 선형 보간 `a + (b-a)·t` |

빌트인으로 바로 쓰는 것: `sqrt`·`abs`·`floor`·`ceil`·`round`·`sin`·`cos`·`exp`·`log`·`pow`.

## 안 지은 것 (정직히)

`atan2`·`asin`·`acos`·`tan`·`log2`·`log10`·`cbrt`·`hypot`(빌트인 버전) · 복소수 · 고정소수 ·
`f32` 전용 얼굴. 필요해지면 같은 자리에 붙는다 — **빌트인 하나 + 이 파일 한 줄**이다.

☞ 그리고 `hyp` 는 `sqrt(x²+y²)` 를 그대로 셈한다 — libm 의 `hypot` 처럼 **오버플로를 피하는
   재조정을 하지 않는다**. 아주 큰 값에서는 다르게 답할 수 있다.
