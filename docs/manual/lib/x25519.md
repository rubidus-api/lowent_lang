# x25519 — 곡선 위의 키 합의

소스: `lib/x25519.low` · 모듈명 `x25519` (RFC 7748 · RFC-0090 N5)

> ## ⚠ 먼저 — 이 구현이 약속하지 못하는 것
>
> · **상수시간을 약속하지 않는다.** 사다리(ladder)는 비밀 비트로 분기하지 않도록 `fsel`(조건부
>   교환)로 짜여 있지만, 이 언어에는 **경계 검사와 트랩**이 있어 타이밍을 *약속할 수 없다*.
> · **감사받지 않았다.** 오라클은 **RFC 7748 §5.2 스칼라곱 벡터**와 **§6.1 DH 왕복**이다.
> · **작은 위수(small-order) 점을 거르지 않는다.** 상대가 보낸 공개키가 0 을 만드는 점일 수 있다 —
>   합의 결과가 **모두 0** 인지 확인하는 것은 **부르는 쪽의 몫**이다.
> · 개인키를 만드는 일(엔트로피)은 여기 없다 — [random](random.md) 과 `cap random` 의 자리다.

## 처음 쓰는 사람에게

**무엇을 하는 모듈인가.** 내 비밀 스칼라와 상대의 공개점으로 **둘만 아는 32 바이트**를 만든다.
그 바이트열을 그대로 키로 쓰지 말고 [hmac](hmac.md) 의 HKDF 로 갈라 쓰는 것이 표준 관행이다.

**부르기 좋은 얼굴은 `agree` 다.**

```lowent
use x25519 .

rem w 는 u64 175 원소 이상 — 작업 공간을 하나로 받는다.
let n u64 be x25519.agree shared mysecret theirpub zbuf w .
guard eq n 32 . else return 1 .
```

## 왜 작업 공간이 하나인가 (`agree` vs `scalarmult`)

`scalarmult` 는 체 원소 아홉과 곱셈 자리를 **따로** 받는다 — 안에서 읽기에는 그편이 낫다.
그런데 부르는 쪽에서 열넷을 늘어놓으면 **파라미터 상한 16 을 금방 먹는다**: 이 라이브러리를
쓴 첫 프로그램이 실제로 `E-IR-ARITY` 로 거절당했다. 그래서 `agree` 가 `w` 하나(≥175 원소)를
잘라 쓴다. **자리 배치는 소스 한 곳에만 있다**(fe 아홉 = `w[0..144]` · 곱셈 자리 = `w[144..175]`).

## 표현을 고른 이야기 (읽어 둘 만하다)

소수는 `p = 2^255 - 19`. 흔한 참조 구현(ref10)은 원소를 **26/25 비트**로 담고 조각이 **음수가
될 수 있게** 두며, 자리올림을 **산술 오른쪽 시프트**로 한다. 그런데 이 언어의 `shr` 은
**논리 시프트**다(`-64 shr 6` 이 `-1` 이 아니다 — 실측으로 확인했다). 그래서 그 배치는 여기서
쓸 수 없다.

⇒ **음수가 아예 없는 표현**을 골랐다(16 조각 × 16 비트, TweetNaCl 배치). 뺄셈은 `a - b` 대신
`a + 4p - b` 로 한다 — `4p ≡ 0 (mod p)` 이므로 값은 같고 **모든 중간값이 음이 아니다**.
☞ 도구의 한계가 표현을 골랐는데, **고른 쪽이 추론하기 더 쉬운 쪽이었다.**

## 표면

| op | 하는 일 | 요구 |
|---|---|---|
| `agree` | 스칼라 × 점 → 공유 비밀 32 바이트 (작업 공간 하나) | `w ≥ 175` · 나머지 32 바이트씩. 답 32, **0 이면 실패** |
| `scalarmult` | 같은 계산, 작업 공간을 낱개로 | 인자 열넷 |
| `fadd`·`fsub`·`fmul`·`fsq`·`finv`·`fsel`·`funpack`·`fpack` … | 체 산술 | 위 배치를 아는 코드용 |

★ 체 산술이 `export` 인 것은 **시험하기 위해서**다(항등식을 골든이 잰다). 새 프로토콜을 짓는
것이 아니라면 `agree` 만 쓰면 된다.

## 오라클

RFC 7748 **§5.2 스칼라곱 벡터**(알려진 입력 → 알려진 출력)와 **§6.1 DH 왕복**(둘이 만나 같은
비밀을 얻는가). 그리고 체 산술의 **항등식**(예: `a·a⁻¹ = 1`). VM ≡ native.

## 안 지은 것 (정직히)

상수시간 보장 · 작은 위수 점 거르기 · 키 생성/클램핑 편의 op · Ed25519 서명(그 자리는 `ed25519`) ·
X448.
