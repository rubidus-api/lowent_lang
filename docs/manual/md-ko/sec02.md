# 이 책을 읽는 법

이 책은 **앞에서 뒤로 읽는 것**을 기준으로 쓰였다. 뒤의 장은 앞의 장이 세운 어휘와 규칙 위에 선다. 각 장의 첫머리에 “먼저 알아야 할 것” 이 장 번호와 함께 적혀 있으므로, 건너뛰어 읽다가 막히면 그 자리로 돌아가면 된다.

다만 읽는 사람의 사정은 저마다 다르다. 아래의 갈래는 자기 자리에 가까운 것을 골라 쓰는 **단축 경로**다.

★ 어느 경로를 고르든 **제1부와 제4부**는 덜어 내지 않는다. 제1부는 이 언어의 목표와 겉모습을, 제4부는 그 목표를 받치는 계약·효과· 권한을 세운다. 나머지 모든 부가 이 둘 위에 서 있다.

## <a id="sx1"></a>길 ① — 이 언어를 처음부터 배운다

책의 차례 그대로다. 제1부부터 제8부까지 차례로 읽고, 제9부는 필요한 장만, 제10부는 마지막 장(50장)만이라도 읽는다.

## <a id="sx2"></a>길 ② — Rust 나 C 에 익숙하고 차이만 알고 싶다

1–3장 → 4·11장 → 제4부 전체(14–17장) → 제5부(18–20장) → 22·23장 → 27장 → 29장. 제2·3부의 나머지는 각 장의 “복습 정리” 만 훑고, 처음 보는 규칙이 있으면 그 장을 읽는다.

## <a id="sx3"></a>길 ③ — 운영체제 없는 기계에서 쓰려 한다

제1부 → 4장 → 제4부 → 18·20장 → 27장 → 29·30장 → 35장. 힙이 거절되는 자리(18장)와 기계의 등급(30장)이 이 길의 핵심이다.

## <a id="sx4"></a>길 ④ — 이 언어의 주장이 어디까지 참인지 알고 싶다

1장 → 14장 → 15장 → 12장 → 제10부 전체. 제10부의 각 장은 앞의 어느 장과 이어지는지 첫머리에 적어 두었다.

## <a id="sx5"></a>본문의 장치

장은 같은 모양으로 시작한다 — 이 장의 차례, 먼저 알아야 할 것, 그것을 꺼내 보는 문답, 이 장이 왜 이 자리에 있는가, 끝나면 무엇을 얻는가, 이 장에서 답할 질문. 본문에는 문답·흔한 오해·실제 사례·수학 상자·시연(예제와 실제 출력)이 나오고, 장 끝의 복습 정리가 요점을 한 번 모은다. 시연의 출력은 검증 스크립트가 남긴 것을 그대로 싣는다. 출력에 보이는 긴 영문 진단은 컴파일러가 실제로 낸 문장이다.
